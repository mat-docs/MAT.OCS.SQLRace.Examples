# Test Data

This directory contains test fixtures for integration tests.

## Generating test data

Test data is generated by the `GettingStartedTests` class, which creates temporary SQLite databases during test runs. These are cleaned up automatically after each test.

For manual testing, use the `GettingStarted` project:

```bash
cd projects/csharp
dotnet run --project GettingStarted
```

This creates a session in the default SQLite database at `%TEMP%/sqlrace-examples.ssn2`.
